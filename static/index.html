Project Technical Architecture & Viva Guide

Course: Computational Thinking and Programming (2026CSAE100) • Collaborative Project

🧠 Computational Thinking Highlights

  • Decomposition: Divided result processing into validation, mathematical calculation, ranking algorithm, and report generation.
  • Pattern Recognition: Grade classification through ordered threshold mapping tuples.
  • Abstraction: Encapsulated student records in standardized dictionaries with clean functional APIs.
  • Algorithm Design: Multi-tiered tie-breaking competition ranking and rule-based diagnostic engine.

🐍 Python Concepts Implemented

  • Lists & Tuples: Immutable grade brackets GRADE_SCALE and sorted student cohorts.
  • Dictionaries: Structured student data and nested subject mark mappings.
  • Sets: Unique failed subject detection and duplicate roll number protection.
  • File I/O: CSV reading/writing via Python csv.DictReader/DictWriter and TXT report generation.
  • Exception Handling: Defensive boundary verification and graceful fallback.
